## ファイル
| ファイル | 内容 |
|---|---|
| `index.html` | ポータル（トップ）：想い・大切にしていること・手づくりの現場・歩み・参加者の声・団体紹介・協賛募集・開催案内一覧。年をまたいで使い続ける |
| `2026/index.html` | 2026 年（第3回）の開催案内ページ。翌年は `2027/` を作り、トップの「次回」を差し替える。過去年は残しておく |
| `2026/apply/index.html` | 申込フォーム。入力内容を Google フォーム（受け皿）へ送信し、スプレッドシートに自動追記される。年ごとに Google フォームを作り直し、`FORM` の URL と `E` の entry ID を差し替える |
| `img\` | Web 用に縮小した写真（元は `..\素材\`。英字ファイル名）とロゴ |
| `QR_サイト_印刷用.png` | サイト URL の QR（濃紺・余白付き、チラシ・ポスター用） |
| `QR_サイト_SNS用.png` | Instagram 投稿・ストーリー用の QR 画像（1080×1080） |
| `.nojekyll` | GitHub Pages の変換処理を止める印（消さない） |

## 更新の仕方（Claude Code に頼むとき）
1. `index.html` を直す（文言・写真）。写真を足すときは `..\素材\` から縮小して `img\` に英字名で置く
2. ブラウザで見た目を確認（スマホ幅も）
3. このフォルダで `git add -A` → `git commit -m "…"` → `git push origin main`
4. 1〜2 分で公開に反映される（`https://mikadzuki-hiking.github.io/` を再読み込み）

## 申込フォームの仕組み（2026）
- 受け皿：Google フォーム「三日月山ファミリーハイキング 2026 申込フォーム」（編集 URL：https://docs.google.com/forms/d/1iXrIFSWbBYlGYJVL9XRE0vKk9yL-HfUcLf66GBdP4X4/edit ）
- 回答の保存先：スプレッドシート https://docs.google.com/spreadsheets/d/1EHbF2LdFqNKEPsbwv0TEidKWaK7GdNXaAD0o_Mxxfv8/edit
- サイト側 `2026/apply/index.html` の `FORM`（formResponse の URL）と `E`（各欄の entry ID）で対応付け。Google フォーム側の質問を増減したら、公開 URL の HTML（`FB_PUBLIC_LOAD_DATA_`）から entry ID を取り直して `E` を更新する
- Google フォームは「公開」済み・「リンクを知っている全員」が回答可でないと 401 になる
- 申込者への自動返信は無し（主催者へのメール通知のみ）。必要なら Google Apps Script に乗せ替える
